Tutorial setup

Install and open ClaimTrace

Install ClaimTrace once, then open it from the same environment whenever you want to review a figure.

Keep this guide open in a separate tab. When the welcome page appears, return to Start here and begin Figure 1B1.

Use Python 3.10 or newer. Check with py --version in Windows PowerShell or python3 --version in Linux, macOS or WSL. Installation downloads the required Python packages; later GUI sessions use the local installation.

Install ClaimTrace

Open a terminal in a folder of your choice and use the commands for your system. .venv holds this installation and its dependencies.

Windows PowerShell

py -m venv .venv
.\.venv\Scripts\python.exe -m pip install claimtrace==1.0
.\.venv\Scripts\python.exe -m claimtrace --version

If your Python installation provides python instead of py, use python -m venv .venv for the first command.

Linux, macOS or WSL

python3 -m venv .venv
.venv/bin/python -m pip install claimtrace==1.0
.venv/bin/python -m claimtrace --version

Check: The last command prints claimtrace followed by its version number. Keep using the same terminal environment for ClaimTrace and its file paths. In WSL, a Windows path such as C:\work\figure becomes /mnt/c/work/figure.

Open the GUI

From the folder where you created .venv:

Windows PowerShell

.\.venv\Scripts\python.exe -m claimtrace gui

Linux, macOS or WSL

.venv/bin/python -m claimtrace gui

The terminal prints an address and opens your browser:

ClaimTrace GUI: http://127.0.0.1:8765

If the browser stays closed, open that printed address yourself. Keep the terminal open during your session. The welcome page offers Choose files, Open package and Try an example.

Return to Start here
Install from a source checkout

For local development, download or clone the ClaimTrace repository. Run the installation commands from the folder containing pyproject.toml, replacing pip install claimtrace==1.0 with pip install ..

The tutorial download contains the reading guide and example data. Use the repository checkout for source installation.

Installation help

Setup help

What you see Next action
Python launcher is unavailable Install Python 3.10 or newer, reopen the terminal, and check its version.
No module named venv or an unavailable ensurepip on Linux Install your distribution's Python venv package, then repeat the installation steps.
pip asks for pyproject.toml or setup.py Use pip install claimtrace==1.0 to install the release. For source installation, run pip install . from the repository folder containing pyproject.toml.
No module named claimtrace Run the install command with the same .venv Python used to launch the GUI.
Port 8765 is occupied Add --port 0 to the GUI command and open the newly printed address.
The browser opens on another desktop or stays closed Add --no-browser, then open the printed address in your preferred browser.
A saved package is hard to locate Check claimtrace-workspace/ in the original launch folder, or use the path shown by Saved locally.
