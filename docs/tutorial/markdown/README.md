Download **Input files** to build the record step by step. Use a **Completed package** to inspect the saved audit or replay a scene in its original molecular viewer. On GitHub, open a ZIP file page and select **Download raw file**, then extract it.

## Use the guide

For each case, extract **Input files** and read `LAB_NOTES.txt` beside the `files/` folder. Select every file inside `files/` in ClaimTrace. Use the field tables to record the supplied observations, sources and interpretation limits. Record your own measurements or replay results after performing those checks.

For molecular viewer replay, extract **Completed package** and follow its `README.md`. Its native scenes and source resources retain the package layout used for replay. The flat `files/` folder supports GUI import.

The completed examples are Working drafts. Their audit rows preserve recorded details and open scientific questions, including pending scene replay and source inputs required for further analysis.
