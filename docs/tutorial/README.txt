ClaimTrace illustrated guide

Start here: open README.md on GitHub, or index.html in a browser. Both introduce the same Prepare, Review and Export workflow.

Install and open the application using setup.html in this tutorial folder, then return to this guide. Keep ClaimTrace and the tutorial in separate tabs.

Choose Start Figure 1B1 to follow Pocket visibility from source files to an exported Working draft. Choose another case opens the 12-case catalogue, grouped by task. Each case supplies input files, field values, screenshots and a completed example.

On GitHub, open a case ZIP file page and select Download raw file. Extract the ZIP before using its files.

For offline reading, download claimtrace-tutorials-1.0.zip from the v1.0 release:
https://github.com/GeraltZeroZhong/ClaimTrace/releases/tag/v1.0
Extract it and open the top-level index.html. Keep the extracted folders together so screenshots and case downloads remain available. The HTML guide includes copy buttons and browser printing.

If you already have a repository checkout or downloaded it with Code > Download ZIP, open docs/tutorial/index.html in that folder.

Open a review package explains how to inspect a received package and add a reader note. Data sources and attribution are in SOURCES.md and sources.html. Upstream licenses are retained in licenses/ and applicable downloads.
