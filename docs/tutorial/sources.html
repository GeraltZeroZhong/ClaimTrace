Tutorial data sources

The 12 tutorials follow the examples in Beyond Display. Their input bundles contain selected real structures, docking poses, derived tables, saved scenes and figures from the accompanying research materials. The completed packages add the claims, evidence links, settings and limitations entered during the illustrated GUI workflow.

Each case below identifies its source system and all imported files. Scientific inputs retain their recorded scope: a structure, a derived measurement and a saved view each contribute a different part of the audit.

Source records

  • Experimental coordinates: RCSB PDB. The cases use the accessioned coordinate files listed below. Cite the corresponding structure records when reusing them.
  • Predicted structure: AlphaFold DB model AF-P69441-F1, version 6, for UniProt P69441.
  • Docking poses and receptor inputs: Xu and colleagues, A Multi-Paradigm Benchmark of Molecular Docking: From Physics to Co-folding and Hybrid Models, version v1, 13 April 2026, DOI 10.5281/zenodo.19560204. The official record identifies the GNINA pose archive, Vina/GNINA PDBQT input archive and results tables. It lists the Creative Commons Attribution 4.0 license.
  • Interaction fingerprints: Bouysset and Fiorucci, ProLIF-paper source repository, archived as version 1.0.0, DOI 10.5281/zenodo.4945869. The included pickle comes from repository revision 5d6d22e. Cite ProLIF: a library to encode molecular interactions as fingerprints.
  • Simulation setup and trajectory-derived tables: GPCRmd dynamic 106, as described by the supplied setup records. The tutorial bundles the selected metadata and derived tables; trajectory replay requires the corresponding topology and trajectory files.
  • Validity-check context: PoseBusters. Case 4C links the supplied findings and measured close contacts to the selected GNINA pose.

Attribution and file variants

The ProLIF source repository applies Apache License 2.0 to its files unless a file states otherwise. Its copyright notice is retained here verbatim:

Copyright 2021 Cédric BOUYSSET

See the original ProLIF license. The case 4E downloads also carry this license. Upstream structures and datasets retain their respective source terms; the ClaimTrace software license covers the software.

The file lists below distinguish deposited coordinates and published datasets from author-prepared scenes, figures and derived analyses. Receptor PDBQT files for the docking cases retain the supplied coordinate records and use portable source labels in their REMARK headers. The case 1B6 replay script loads the saved PyMOL session. Each download includes its source attribution and applicable upstream license notices.

The flat files/ folders are prepared for GUI import. Native PyMOL replay uses the folder layout in a completed example package. In case 1B6, run the replay script from that completed package’s root so that its native/ path resolves.
