# ClaimTrace 1.0

ClaimTrace 1.0 brings the figure review workflow to a local GUI, guided terminal
and companion agent skill. Each review connects **Claim → Visual evidence →
Provenance → Uncertainty → Reproducibility** in a shared package.

## Work with a figure

- Prepare, review and export through Basic or Expert GUI modes, or the CLI.
- Start from PyMOL, ChimeraX or MolViewSpec scenes, images and supporting files.
- Review agent suggestions with their sources, proposed values and decision history.
- Follow 12 illustrated tutorials with downloadable inputs and completed examples.

This release preserves native selection provenance when applying unchanged
answers, renews review status after scientific content changes, and keeps
current answers aligned with guided edits. Multiple native scenes retain
separate views, and resource matching resolves explicit paths before filenames.
Shared evidence keeps its selected targets during terminal editing.

Visual meanings follow their selected scene and operation. Selection edits
require a fresh runtime check, and changing an evidence link updates both linked
records. Section-by-section completion uses the latest saved records and retains
progress in other sections. Package records use atomic file replacement, and ZIP
export accepts source files with dates outside the ZIP timestamp range.

## Upgrade from 0.1.0

In the environment where you use ClaimTrace:

```bash
python -m pip install --upgrade claimtrace==1.0
python -m claimtrace --version
```

For a source checkout, use `python -m pip install .` from the new checkout.
Stop an existing GUI session, then restart it with the upgraded environment.

Keep an original copy of important packages. Open a package folder directly;
extract a received ZIP first. Schema `0.1.0` packages remain readable. Review
the findings before exporting: improved checks may identify context to add.
Editing a received export through the GUI, guided terminal or agent commands
creates a working copy and reports its path.

Refresh an installed skill by retaining the old skill folder separately and
running `claimtrace skill --out` with the desired fresh destination. Keep the
skill and Python package from the same release.

CAL and validation-report schema versions remain `0.1.0`; the agent protocol
is `"1"`. Read [Interface contracts](../interfaces.md) for persistence behavior,
exit codes and compatibility commitments.

## Scientific scope

Validation checks the files, references and context required for the selected
purpose. Native viewer replay, numerical analysis and scientific interpretation
retain their own source evidence. Open scenes in their original viewer and link
the resulting renders, logs or measurements when they support the claim.
